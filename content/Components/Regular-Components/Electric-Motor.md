The electric motor is a build-mode exclusive component that can be used to **rotate** objects at a set speed. It was first showcased on the ==Aerodynamics update== trailer.

The electric motor is a very **convenient** way to rotate objects.

The electric motor looks like a miniature version of the [[Components/Regular-Components/Servo|Servo]].

## Usage
- To create ==cars== as it can control the speed of each wheel.
- To create ==helicopter rotors==.
- To create things such as ==ferris wheels==.

Note that the electric motor has a max rotation speed of 150 in either directions. However, this can be bypassed by gluing electric motors to the tips of each other, mind that this will create ==**lag**== if overdone.
