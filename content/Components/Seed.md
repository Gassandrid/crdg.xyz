The **Seed** is a **Component** obtainable through the [[items/regular-items/component-machine|Component Machine]]. It resembles a small seed.

## Function

The Seed's sole function is it can be used in conjunction with the [[components/planter|Planter]] to grow Trees that can drop [[features/manifests|Manifest components]]. More information about this process can be found in the [[components/planter|Planter]] article.
