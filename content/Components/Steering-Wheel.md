## Overview

The Steering Wheel, being added in the Aerodynamics Update, is a component that allows you to steer any vehicle you attach it to. It can be spawned in with the [[Component Machine]].

## Properties

| Property | Value |
| --- | --- |
| Type | Regular component |

## Usage

The Steering Wheel, as expected, allows you to steer anything you attach it to. However, instead of turning your doohickey left and right, it TILTS it left and right. The component uses the Roblox dragging system, similarly to the controllers like the Super Hubert Man or the Block Matcher Design Pro 3K. The component is kind of difficult to use but once you get the hang of it you'll be fine.
